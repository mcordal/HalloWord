# HalloWord

Este é um projeto simples em Python que imprime "Hello, World!" no terminal.

## Como executar

1. Certifique-se de ter o Python instalado (recomendado Python 3.10 ou superior).
2. No terminal, navegue até a pasta do projeto.
3. Execute o comando:

   ```sh
   python main.py
   ```

Você verá a mensagem:

```
Hello, World!
```
